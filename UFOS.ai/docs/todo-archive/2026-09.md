### Global Monitoring System — verification history 2026-09-22 … 09-24 (all [x])

(original lines 1126–1307 of docs/todo.md as of 2026-10-24, verbatim)

  - [x] **2026-09-24: flight/disaster Assess input enriched.** Flights and
    disasters gave the Assess/Sentiment button almost nothing to work with
    ("input too sparse to derive substantive insight"). `military_registry.py`
    now maps each known callsign prefix to a plain-English description
    (`describe_callsign()`), and `opensky_collector.py` reports ground
    speed, climbing/descending/level, squawk code, and a compass heading —
    not just altitude and a raw heading number. `gdacs_collector.py` now
    uses GDACS's own `<description>` sentence (real substance: date, what
    happened, magnitude, who's affected) instead of a terse
    `"EQ — Tonga — Magnitude 5.7M"` tag line, plus alert level and
    population-affected text.
  - [x] **2026-09-24: long headlines truncated on the globe.** A marker's
    on-globe label now truncates to ~46 characters with "…"
    (`truncateLabel()` in `globe.html`); the sidebar's "Selected" panel is
    unaffected and always shows the full title/summary.
  - [x] **2026-09-24: GDELT rate-limited again for `/localnews`.** The
    existing circuit breaker's minimum request spacing (5s) still wasn't
    conservative enough in practice. Raised `GDELT_MIN_REQUEST_INTERVAL_SECONDS`
    to 12s and `LOCALNEWS_CACHE_SECONDS` to 30 minutes (from 5) — a capital
    city's local news doesn't need re-fetching every few minutes, so fewer
    requests in the first place is the real fix, not just surviving 429s
    better.
  - [x] **2026-09-24: news markers placed at the story's actual subject, not
    the reporting outlet's country.** GDELT's DOC 2.0 API only gives the
    source outlet's country, never a per-article location — a story
    headlined "Renewed fighting in north Ethiopia..." from a Syria-flagged
    outlet was landing near Syria, nowhere near Ethiopia. `geo.py`'s new
    `detect_mentioned_country()` scans the headline for a known
    country/hotspot name (last mention wins — "Russian strikes on Ukraine"
    now places in Ukraine, not Russia) and `gdelt_collector.py` places the
    marker there when found, falling back to source-country placement
    otherwise. A coarse keyword heuristic, not real geocoding.
  - [x] **2026-09-24 (abends): Assess scheiterte mit 400 ("Requested token
    count exceeds the model's maximum context length").** `assess.py` setzte
    kein `max_tokens`; manche OpenRouter-Upstream-Provider (gesehen:
    GMICloud) reservieren dann das gesamte Kontextfenster (131072) für die
    Antwort — schlägt je nach Routing sporadisch fehl. Fix: explizites
    `max_tokens=400`, Provider-Fehler werden zu einer lesbaren Zeile
    gekürzt (voller Fehler weiterhin in `backend.log`).
  - [x] **2026-09-24 (abends): GDELT 429 schon beim ersten Request nach
    Neustart.** GDELT sperrte die IP noch von früheren Tests, der Cooldown
    lag aber nur im Speicher und wurde bei jedem Neustart gelöscht; 30s
    Start-Cooldown war zudem viel kürzer als GDELTs echte Sperrzeit.
    `gdelt_client.py` speichert den Cooldown jetzt in
    `data/gdelt_cooldown.json` (überlebt Neustarts, git-ignored), startet
    bei 2 Minuten (Verdopplung bis max. 15 Minuten) und meldet einen
    lesbaren Satz statt `429, message=..., url=...`. Zusätzlich: scheitert
    `/localnews`, zeigt das Panel passende Stories aus dem bereits
    geladenen Geopolitics-Feed (mit Hinweis) statt nur eines Fehlers.
  - [x] **2026-09-24: Insider Trades — echte Form-4-Details + "✦ Sum up
    most notable"-Button.** *(Feature since 2026-09-24 in the HedgeFund module — see the Financial Newsroom item above.)* `sec_edgar_collector.py` parst jetzt jedes
    Form-4-XML selbst (Emittent/Ticker, Person/CIK, Rolle, Kauf/Verkauf,
    Stückzahl, Preis, Wert, Bestand danach) statt nur den Feed-Titel; Karten
    im Popup zeigen das direkt. Neuer Button im Popup (gleiches Design wie
    Refresh) ruft `POST /insider-summary` auf: `insider_summary.py` baut eine
    kompakte, nach Dollarwert sortierte Tabelle mit im Code berechneten
    Flags (OPEN-MARKET-BUY, CROSS-COMPANY — gleiche Person Insider bei
    mehreren Firmen, BIG-STAKE-CHANGE, 10%-OWNER, routine-compensation),
    OpenRouter fasst die größten und ungewöhnlichsten Trades zusammen.
    Cross-Company-Erkennung nur innerhalb der ~50 geladenen Filings.
  - [x] **2026-09-24: vergangene Wettermeldungen gefiltert + Häkchen filtern
    auch die Event-Feed-Liste.** `gdacs_collector.py` verwirft Alerts, deren
    `<gdacs:todate>` mehr als `GDACS_MAX_HOURS_SINCE_END` (48h) zurückliegt
    oder die GDACS als nicht mehr aktuell markiert; `main.py` entfernt
    abgelaufene Alerts alle 10 Minuten auch zur Laufzeit (WebSocket-Nachricht
    `remove`). In `globe.html` blenden die Layer-Häkchen links jetzt Globus
    UND Event Feed rechts gemeinsam ein/aus.
  - [x] **2026-09-24: Insider Trades — nur 3 von 100 Feed-Einträgen waren
    Form 4; lesbare Zusammenfassung; Auto-Refresh.** *(Feature since 2026-09-24 in the HedgeFund module — see the Financial Newsroom item above.)* EDGARs `type=4` ist ein
    Präfix-Filter (liefert auch 424B2-Prospekte etc.) — Collector blättert
    jetzt durch den Feed bis 40 echte Form-4-Filings. Transaktionen tragen
    jetzt das gehandelte Wertpapier (Common Stock, Stock Option …), auch
    Derivate werden geparst. Prompt verlangt einen klaren Satz pro Trade
    (wer, gekauft/verkauft, wie viele von welchem Wertpapier welcher Firma,
    Gesamt- und Stückpreis, Datum, Bestand danach), gegliedert in "LARGEST
    TRADES" / "MOST UNUSUAL", keine Codes wie (P). Popup lädt alle 10s still
    neu (nur lokales Backend, keine zusätzlichen SEC-Anfragen).
  - [x] **2026-09-24: Insider-Popup plötzlich leer — SEC-Timeout.** *(Feature since 2026-09-24 in the HedgeFund module — see the Financial Newsroom item above.)* Ein
    langsamer EDGAR-Feed-Request lief ins 20s-Timeout (leere Fehlermeldung im
    Log, weil Timeout-Exceptions kein `str()` haben); mit dem neuen
    Mehrseiten-Abruf verwarf eine langsame Seite den ganzen Poll. Jetzt: 45s
    pro Seite + 1 Retry, bereits geladene Seiten werden behalten,
    fehlgeschlagener Poll wiederholt nach 30s statt 120s, Fehler mit
    Exception-Typ geloggt; Popup-Hinweis beschreibt die echte Ursache.
  - [x] **2026-09-24 (nachts): Backend wurde von der App nie selbst
    gestartet.** `MainWindow.xaml.cs` suchte `run_backend.ps1` unter
    `<exe>\..\..\..\backend\` — richtig nur für die eigenständige
    `GlobalMonitoring.exe`. Aus der UFOS.ai-Haupt-App geöffnet (Normalfall,
    alle Module im selben Prozess) zeigte das auf `UFOS.ai\backend\...`,
    das es nicht gibt; das Backend lief nur, solange es per Hand

  - [x] **2026-09-24 (nachts): GDELT komplett ersetzt.** GDELT lieferte

  - [x] **2026-09-24 (nachts): Debugger-Stop hinterließ verwaisten
